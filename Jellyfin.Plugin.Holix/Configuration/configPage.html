Holix Play

Household and profile mapping for the Holix Play client. Each profile is a hidden Jellyfin user; birth dates and PINs never reach this server (they stay in holix-cloud) — only the parental limit derived from the age rating is written here. In a cloud-linked household, a profile session is opened with a short-lived proof that holix-cloud signs after verifying the PIN.

Announced to clients in /Holix/Info. When linking a household, the plugin only contacts this URL (link code + public keys). Must use https. Default: the hosted Holix Play cloud.
When on, the owner token alone is not enough: a PIN-protected profile cannot be opened until holix-cloud verifies the PIN, and the profiles' cloud mapping is locked.
When off (transition period), unlinked households keep the old behaviour and sessions open with a warning.
Devices signed in to a linked household's Holix account get the owner's session without the Jellyfin password (short-lived proof signed by holix-cloud). Profile PINs still apply.
Each profile is a hidden Jellyfin user. However many profiles a household has, together they can watch on at most as many screens as the owner's own limit (Dashboard → Users → owner → "Maximum number of simultaneous user sessions").
Profiles never get more rights than their owner, and the owner's session limit covers the whole household. Administrators can always create a household. Changing this only affects new households; existing ones keep working.
Empty: loopback and private networks only. Requests from other addresses get 404.
